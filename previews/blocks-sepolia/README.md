# First blocks token on Ethereum Sepolia

Token 1194011 — ALLEY. These GIF and AVI files are original bytes generated by
the deployed Solidity contracts, without transcoding. The GIF was extracted from
the full tokenURI metadata response; the AVI came from `avi(1194011)`. Each read
used a 500,000,000-gas cap. Pillow and FFmpeg independently confirmed 128×128,
90 frames, a six-second loop, and exact RGB equality between GIF and AVI.

Addresses, receipts, media hashes and byte sizes: `deployments/blocks-sepolia.json`.
The full metadata response is omitted here because it duplicates the GIF data.
